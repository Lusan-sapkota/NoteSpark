Changelog

Every notable update to NoteSpark, from the initial release to the Material 3 Firefly redesign.

Material 3 Firefly redesign & offline features

October 25, 2026

Quicker writing and better finding

A scratchpad in every profile
Jot things down without making a note. File the selection or everything as a note when it's ready, or clear it with Undo. Its tasks show on the Tasks screen, and text shared to NoteSpark lands there by default.
Faster capture in the editor
The title is optional (the first line is used instead), lists and tasks continue when you press Enter, and new Task and Due date buttons sit on the toolbar. Typing # or [[ suggests your existing tags and note titles.
Unsaved changes are kept
Leaving with changes asks first, and a draft survives the app being closed in the background.
Repeating tasks and a reminder time
Add every:day, every:week, every:month or every:year to a task: ticking it moves the due date on. Choose when reminders arrive in Settings, and show done tasks on the Tasks screen.
Find in a note, history with changes, and Rediscover
Find and jump between matches in long notes. Version history marks what changed. Rediscover shows one older note a day on Home. Search by meaning now reads long notes all the way through.
Links that follow renames, and Mentioned in
Renaming a note updates every [[link]] to it. A Mentioned in list finds notes that name this one, with a one-tap Link.
Markdown import and auto-lock
Restore now takes Markdown, text and zip files from other apps. Locked profiles ask for the PIN again after time in the background.

Profiles, PINs and encryption

Separate profiles with SQLCipher encryption
Keep separate sets of notes (Personal, Work, and more), each in its own SQLite database. Lock any profile with a four-digit PIN or fingerprint unlock. Protected profiles are encrypted on your phone with SQLCipher and a random 256-bit key in Android's secure storage.
Move notes between profiles
Move a note from its menu or select several notes on Home to move them together, along with their version history and an Undo option.
PIN safety, 30-day profile bin, and phone transfer support
PINs are stored as salted SHA-256 hashes with exponential lockout after 5 wrong attempts. Deleted profiles stay in a 30-day profile bin. A PIN-wrapped backup of each locked profile's key lets locked databases unlock with your PIN after an Android device-to-device transfer.

Organising, search by meaning and links

On-device search by meaning and Related notes
Bundled all-MiniLM-L6-v2 int8 ONNX model and sqlite-vec index your notes on the phone so you can search by concept without internet access, and see up to 5 Related notes at the bottom of a note.
[[Note title]] links, #tags, Archive, and multi-select
Link notes together with [[Note title]] syntax and view a "Linked from" list on the target note. Type #tags in any note to get filter chips on Home. Archive notes to hide them from the main list, or long-press on Home to select several notes at once.
30-day note bin
Deleted notes move to the Bin (in Settings) where they stay for 30 days before being erased for good, with instant Undo when binning from Home or a note.

Editor, tasks, backups and quick capture

Tasks screen, due dates, and reminders
Every open - [ ] task across your notes appears on the Tasks screen, grouped by due date (Overdue, Today, Upcoming, using due:YYYY-MM-DD or 📅 YYYY-MM-DD) or by note. Local notifications remind you at 9:00 on the due date.
Editor undo/redo and 20-version note history
Undo and redo up to 100 steps while editing. Every save keeps the previous version (up to 20 per note) under Version history on the note page so you can read and restore earlier text.
Automatic folder backups, Markdown .zip export, and offline image cache
Schedule daily or weekly JSON backups to a folder on your phone (keeping the last 5 per profile), export notes as a Markdown zip with YAML front matter, and view web images offline after their first load.
Home-screen widget, app shortcut, and Share to NoteSpark
Added the 4×2 Firefly Pinned notes widget, a long-press "New note" launcher icon shortcut, and Android share-sheet support to send text or links straight into a new note.

Material 3 Firefly design and strict offline architecture

Firefly theme, Figtree & Literata fonts, and n-spark logo
Rebuilt every screen on Material 3 Tonal Spot roles from seed #9BBF2A in Light, Dark, and System modes, with bundled Figtree and Literata static fonts, segmented tonal lists, and the new n-spark icon.
Removed all background network code
Removed expo-updates and @react-native-community/netinfo so the app never contacts an external server on launch. Added an in-app Privacy policy screen.

Version 1.0.0

July 13, 2025
Initial public release of NoteSpark
Create, edit, and delete notes in Markdown or plain text, pin important notes to the top, sort by last edited or created date, and filter by title, text, or format.
JSON backup, restore, and PDF history
Import and export notes as JSON for local backup, and view or save import/export history as a PDF.
Offline-first and open source
Built with Expo, React Native, and SQLite with dark mode support under the GPLv3 license.
