# NoteSpark

Private, offline notes. No accounts, no ads, no tracking: your notes stay on your device.

| Folder | What it is | Status |
|---|---|---|
| [`Mobile/`](./Mobile) | The Android app (Expo, React Native, TypeScript) | Available as an APK on [GitHub releases](https://github.com/Lusan-sapkota/NoteSpark/releases); Google Play and F-Droid coming soon |
| [`Desktop/`](./Desktop) | Desktop app for Linux, Windows and macOS (Electron), syncing with the phone over your own network | Coming soon |
| [`Docker/`](./Docker) | Self-hosted sync hub that keeps every note as Markdown | Coming soon |
| [`Web/`](./Web) | The website, [notespark.lusansapkota.com.np](https://notespark.lusansapkota.com.np) | Live |

## Mobile app

```bash
cd Mobile
npm install
npx expo start
```
