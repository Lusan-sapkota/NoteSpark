# NoteSpark

A fast, offline-first notes app built with Expo, React Native, and TypeScript. No accounts, no ads, and your notes stay on your device.

> NoteSpark is being redesigned and is coming to the Play Store.

## Development

```bash
npm install
npx expo start
```
