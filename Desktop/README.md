# NoteSpark for desktop

Coming soon. An Electron app for Linux, Windows and macOS that syncs with the phone over your own Wi-Fi or a private tunnel (Tailscale, WireGuard), never through a server.

Planned: the sync hub runs inside the app, keeps every note as a Markdown file you can open anywhere, and stays in the tray to sync. No auto-updater, analytics or crash reporting: like the phone app, it makes no network requests except to your own paired devices.
